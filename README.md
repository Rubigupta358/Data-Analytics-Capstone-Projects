# Data Analytics Capstone Projects

This repository contains the two requested capstone projects:
- DA-01 Enterprise Business Intelligence Suite
- DA-02 Customer 360 and Marketing Attribution

Each project folder includes source data, SQL or Python, model files, build notes and
dashboard requirements. The Power BI `.pbix` and Tableau `.twbx` workbooks are to be
created and added after building the dashboards in the respective applications.

## Folder structure
- `DA-01_Enterprise_BI/`: star schema sales BI project.
- `DA-02_Customer_360_Marketing/`: customer analytics and marketing attribution project.
- `submission/`: test checklist, project presentation outline and reflection template.

## Important
Sample CSVs are synthetic and are labelled as such. DA-02 includes GA4 BigQuery queries
for the public ecommerce sample. Configure cloud services and run the queries/dbt models
in your own Google Cloud project before claiming a live cloud deployment.
